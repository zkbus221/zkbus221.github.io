# ZK's bus tracker
A TfL bus tracker made in the support of Claude (AI). 

# How to use
Recommended for iOS 13 and above:
Just press [this](https://zkbus221.github.io/) 

Recommended for iOS 7-13:
Just press [this](https://zkbus221.github.io/legacy/) 

Recommended for iOS <=6:
Just press [this](https://zkbus221.github.io/ios6/) 

## Source used:
TfL Live Bus Data - https://api-portal.tfl.gov.uk/api-details#api=StopPoint&operation=Forward_Proxy

OpenStreetMap - https://www.openstreetmap.org/

Proxy - deployed myself with Cloudflare
