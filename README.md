# ZK's bus tracker
A TfL bus tracker made in the support of Claude (AI). 

# How to use
Just type zkbus221.github.io in your browser and it should work

## Source used:
TfL Live Bus Data - https://api-portal.tfl.gov.uk/api-details#api=StopPoint&operation=Forward_Proxy

OpenStreetMap - https://www.openstreetmap.org/

Proxy - deployed myself with Cloudflare
